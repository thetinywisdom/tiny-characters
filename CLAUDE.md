# Instructions for agents working in this repository

Tiny Characters: the tiny pixel people from Tiny City Builder's bubble lab
(thetinywisdom/character-creator). Read `README.md`, `SKILLS.md` and
`PLAN.md` before working.

- **Keep the docs up to date. With every change, in the same commit:**
  update `SKILLS.md` (files, API, how a person is drawn, workflows),
  `PLAN.md` (move finished work to Done, add next steps, known issues and
  the owner's decisions) and `README.md` (what people see and use).
- Keep the characters as small and simple as they are (the owner liked them
  this way); no build step, no dependencies.
- Check changes visually (Playwright screenshots of `index.html` on a desktop
  size and a phone), with no page errors.
- The owner writes comics in Japanese: when asked for help with Japanese
  (signs, text), include the hiragana reading, an English translation and
  grammar notes.
